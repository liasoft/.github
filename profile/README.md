# Liasoft

**Native developer software for low-level engineers.**

Liasoft builds native developer software for low-level engineers: C++ code coverage, compile-time C++ obfuscation, and native Windows debugging. We are the makers of covdbg and antispy, and supporters of mcp-windbg and dap-dbgeng.

## Products

| | |
| --- | --- |
| **[covdbg](https://covdbg.com)** | C++ code coverage on Windows through binary instrumentation. Point it at your existing .exe with debug symbols: no source changes and no rebuilds. Minimal overhead, coverage inline in your editor, and LCOV, GCOV and HTML reports for your CI. |
| **[antispy SDK](https://antispy.xyz)** | Compile-time C++ obfuscation. It encrypts strings, virtualizes critical code and obfuscates control flow, with no post-build step. One library across Windows, Linux, macOS, Android, iOS and bare metal. |

## Open source we support

- **[mcp-windbg](https://github.com/svnscha/mcp-windbg)**: Model Context Protocol for WinDbg. Crash-dump triage and live debugging driven by AI assistants.
- **[dap-dbgeng](https://github.com/svnscha/dap-dbgeng)**: Debug native Windows code, including services and the kernel, straight from Visual Studio Code, using the engine that powers WinDbg.
- **[lit-ui](https://github.com/liasoft/lit-ui)**: A Bootstrap 5 web-components UI kit built with Lit.
